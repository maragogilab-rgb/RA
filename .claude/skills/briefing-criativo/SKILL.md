# Briefing criativo

## 1. Extraia (ou pergunte uma única vez, agrupado)

| Campo | Pergunta | Padrão se ninguém responder |
|---|---|---|
| Objetivo | O que a pessoa deve **fazer** depois de ver? | Lembrar da marca |
| Público | Quem é, idade, contexto de uso | Público atual da marca |
| Mensagem única | Se ela lembrar de uma frase, qual? | Extrair do pedido |
| Formato/canal | Feed, story, carrossel, impresso, banner | Feed 1080×1350 |
| Marca | Cores, fontes, logo, tom de voz | Buscar no projeto |
| Obrigatórios | Logo, preço, data, endereço, @, QR, disclaimer | Logo + @ |
| Restrições | O que não pode | — |
| Referências | Algo que gostou/odiou | — |

Declare as suposições no topo da resposta: "Assumi: …".

## 2. Hierarquia de conteúdo
Ordene os textos: **1 título** (≤ 7 palavras), **1 apoio** (≤ 15 palavras), **1 CTA** (verbo no imperativo), e o resto vai para a legenda.

## 3. Direções de conceito (2–3)
Para cada uma, 4 linhas:
- **Nome + ideia** (ex.: "Maré baixa — o produto como achado na areia")
- **Visual**: composição, tipo de imagem (foto, ilustração, só tipografia)
- **Paleta**: 3–5 hex com papel (fundo, texto, destaque)
- **Tipografia**: título + texto (Google Fonts)

Varie de verdade: uma segura/na marca, uma ousada, uma tipográfica ou minimalista.

## 4. Critério de escolha
Escolha a que comunica a mensagem única mais rápido no tamanho real (miniatura no celular). Justifique em uma frase.
