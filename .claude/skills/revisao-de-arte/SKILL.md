# Revisão de arte

Abra a imagem final com `Read` e avalie **olhando o arquivo renderizado**, não o código.

## 1. Primeiros 3 segundos
- Qual é a primeira coisa que o olho vê? É a mensagem principal?
- Dá para entender a peça em miniatura (25%)?

## 2. Checklist técnico
| Item | Critério |
|---|---|
| Tamanho | Exatamente o do canal (ver `artes-redes-sociais`) |
| Área segura | Nada importante nas bordas / interface do app / corte |
| Contraste | ≥ 4.5:1 texto comum, ≥ 3:1 texto grande |
| Texto | ≥ 22 px em post 1080; máximo ~25 palavras na arte |
| Fontes | ≤ 2 famílias, carregadas (sem fonte de sistema substituindo) |
| Alinhamento | Tudo na grade; margens consistentes |
| Marca | Cores e logo corretos, logo sem distorção, área de proteção |
| Ortografia | Acentos, crase, maiúsculas, preço/data/telefone/@ conferidos |
| Imagem | Sem pixelização, sem artefatos de IA (mãos, textos falsos, bordas) |
| Série | Consistente com as outras peças da campanha |

## 3. Anti "cara de IA"
Marque e corrija: degradê roxo/azul genérico, brilho e sombra em tudo, ícones aleatórios, emojis decorativos, tudo centralizado sem motivo, cards arredondados empilhados, texto genérico ("Descubra o poder de…").

## 4. Formato da crítica
```
Nota: 7/10
Funciona: … (2 pontos)
Ajustar: 1) … (o mais importante primeiro, com a correção concreta)
         2) …
Variação sugerida: …
```

Se a peça é sua, aplique os ajustes, renderize de novo e só então entregue.
